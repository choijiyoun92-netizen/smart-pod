# POD 문제지·해설지 웹 목업 v7

## 실행

1. ZIP 파일을 압축 해제합니다.
2. VS Code에서 폴더를 엽니다.
3. `index.html`을 직접 열거나 VS Code의 **Live Server** 확장으로 실행합니다.

외부 라이브러리와 빌드 과정이 없는 HTML/CSS/JavaScript 목업입니다.

## v7 수정사항

- 상단 디자인 선택 옵션 및 선택 기능 제거
- 디자인명 표시 제거
- 녹색 방패 형태의 상단 디자인을 문제지·해설지에 공통으로 고정 적용
- 상단 바 구성:
  - 문제지 / 해설지
  - 해설지 구성
  - 1단 / 2단
  - 다운로드
  - 문의
- 문의 버튼을 다운로드 버튼 오른쪽 최우측에 배치

## 주요 파일

- `index.html`
- `styles.css`
- `app.js`
