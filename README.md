# POD 문제지·해설지 웹 목업 v4

## 실행

1. ZIP 파일을 압축 해제합니다.
2. VS Code에서 폴더를 엽니다.
3. `index.html`을 브라우저에서 직접 열거나 VS Code의 **Live Server** 확장으로 실행합니다.

외부 라이브러리와 빌드 과정이 없는 순수 HTML/CSS/JavaScript 목업입니다.

## v4 문의 기능 수정

- 문의 유형이 `문항 오류` 또는 `답안 및 해설 오류`일 때:
  - 문항번호 선택 영역 노출
  - 문항번호에 따라 문항 key 자동 조회
  - 문항 key는 관리자 확인용 읽기 전용 필드로 표시
- 문의 유형이 `시험지 출력 기능 오류`일 때:
  - 세부 기능 선택 영역 노출
  - 상단 디자인 선택 오류
  - 1단/2단 출력 오류
  - 다운로드 오류
- `기타` 선택 시 추가 선택 영역 미노출
- 문의 유형 전환 시 필요한 항목만 필수값으로 적용
