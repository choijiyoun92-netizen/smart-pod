# POD 문제지·해설지 웹 목업 v6

## 실행

1. ZIP 파일을 압축 해제합니다.
2. VS Code에서 폴더를 엽니다.
3. `index.html`을 직접 열거나 VS Code의 **Live Server** 확장으로 실행합니다.

외부 라이브러리와 빌드 과정이 없는 HTML/CSS/JavaScript 목업입니다.

## v6 수정사항

- 좌측 설정 패널 완전 제거
- 상단을 다음 순서로 재구성
  - 문제지 / 해설지
  - 상단 디자인
  - 해설지 구성
  - 문의
  - 1단 / 2단
  - 다운로드
- `해설지 구성` 드롭다운에서 정답·해설 선택
- 선택 상태를 버튼에 `정답 · 해설`, `정답`, `해설`로 요약 표시
- 문제지 탭에서도 해설지 구성을 미리 설정할 수 있으며 선택값 유지
- 미리보기 영역을 화면 전체 너비로 확장
- 문의 입력란 하단의 별도 강조 안내문 제거
- 시험지 출력 기능 오류의 문항번호 필수 안내는 입력란 placeholder로 유지

## 주요 파일

- `index.html`
- `styles.css`
- `app.js`
