√3 + √5를 √(3 + 5)로 계산할 수 없는 이유

오른쪽 그림은 한 변의 길이가 √3 + √5인 정사각형 안에 한 변의 길이가 각각 √3, √5인 두 정사각형을 그린 것이다. 이 그림을 이용하여 √3 + √5를 √(3 + 5)로 계산할 수 없는 이유를 설명해 보자.

문제

다음을 계산하시오.

  1. √21 ÷ √3 + √14 × √2
  2. √15 × 1√3 − √10 ÷ 1√2
  3. √3(√5 + √12) + √60
  4. 5√5 + (2√42 − √35) ÷ √7
힌트
  • 근호를 포함한 식에서는 곱셈과 나눗셈을 먼저 계산한다.
  • 곱하거나 나눌 수 있는 제곱근끼리 먼저 정리한다.
해설

주어진 그림에서 한 변의 길이가 √3 + √5인 정사각형의 넓이는 3 + 5 = 8보다 큼을 알 수 있다. 이때 넓이가 8인 정사각형의 한 변의 길이는 √8이고, 정사각형은 넓이가 클수록 한 변의 길이도 크므로 √3 + √5 > √8이다.

따라서 √3 + √5 ≠ √(3 + 5)이므로 √3 + √5를 √(3 + 5)로 계산할 수 없다.

해설
  1. √21 ÷ √3 + √14 × √2 = √21√3 + 2√7 = √7 + 2√7 = 3√7
  2. √15 × 1√3 − √10 ÷ 1√2 = √5 − √5 = 0
  3. √3(√5 + √12) + √60 = √15 + 6 + 2√15 = 6 + 3√15
  4. 5√5 + (2√42 − √35) ÷ √7 = 5√5 + 2√6 − √5 = 4√5 + 2√6

정답: 3√7, 0, 6 + 3√15, 4√5 + 2√6
